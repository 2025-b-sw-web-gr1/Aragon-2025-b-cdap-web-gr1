👋 BIENVENIDO AL PROYECTO 001

═══════════════════════════════════════════════════════════════

¿QUÉ ES ESTE PROYECTO?

Una API REST completa documentada con Swagger/OpenAPI que gestiona 
Equipos (Teams) y Jugadores (Players) con relación 1:N.

═══════════════════════════════════════════════════════════════

📖 PARA EMPEZAR - LEE ESTOS ARCHIVOS EN ESTE ORDEN:

1. ⭐ LEEME.md                - Resumen visual (2 min)
2. 📘 README.md              - Documentación completa (10 min)
3. 🧪 EJEMPLOS.md            - Ejemplos de requests (5 min)
4. ✅ CHECKLIST.txt          - Verificación (2 min)

═══════════════════════════════════════════════════════════════

🚀 INICIO RÁPIDO (3 PASOS):

1. npm install
   └─ Instala todas las dependencias

2. npm run start:dev
   └─ Inicia el servidor en puerto 3000

3. http://localhost:3000/api
   └─ Abre Swagger en el navegador

❓ PREGUNTAS FRECUENTES

P: ¿Qué versión de Node necesito?
R: Node.js 16+

P: ¿Qué puertos usa?
R: Puerto 3000 (http://localhost:3000)
   Swagger está en: http://localhost:3000/api

P: ¿Cómo pruebo los endpoints?
R: Abre http://localhost:3000/api en el navegador
   Cada endpoint tiene un botón "Try it out"

P: ¿Dónde está la base de datos?
R: Se crea automáticamente como database.sqlite
   Está en la raíz del proyecto

P: ¿Qué endpoints hay?
R: Lee EJEMPLOS.md o abre Swagger en /api

P: ¿Cómo agrego nuevos endpoints?
R: Agrega decoradores @Api* en el controlador
   (ver STATUS.md para ejemplos)
