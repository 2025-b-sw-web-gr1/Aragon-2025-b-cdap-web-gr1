✅ DECORADORES UTILIZADOS

En Controladores:
   @ApiTags('category')
   @ApiOperation({ summary, description })
   @ApiResponse({ status, description, type })
   @ApiBadRequestResponse({ description })
   @ApiNotFoundResponse({ description })
   @ApiParam({ name, description, example })

En DTOs y Entidades:
   @ApiProperty({ example, description, minLength, required, type })

📊 BASE DE DATOS

Tipo: SQLite
ORM: TypeORM

Tablas:
   teams
   ├─ id: INTEGER (PrimaryKey)
   ├─ name: VARCHAR
   └─ country: VARCHAR
      └─ OneToMany → players

   players
   ├─ id: INTEGER (PrimaryKey)
   ├─ name: VARCHAR
   ├─ position: VARCHAR
   └─ teamId: INTEGER (ForeignKey)
      └─ ManyToOne → teams

Relación: 1 Team : N Players (Cascade delete)
